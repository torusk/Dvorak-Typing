# ZenDvorak — A Mindful Typing Experience

> 一打一打を、精神の統一に。  
> **Official Site:** [https://zen.torus-studio.tech](https://zen.torus-studio.tech)

ZenDvorak（ゼン・ドヴォラック）は、日本の「禅（Zen）」の精神に基づき開発された、洗練されたDvorak配列専用のタイピング練習プラットフォームです。無駄を削ぎ落としたミニマルなインターフェースが、指先から始まる瞑想的な体験を提供します。

## 🧘‍♂️ コンセプト
現代のデジタル世界はノイズに満ちています。ZenDvorakは、タイピングを単なる「入力作業」から「精神を研ぎ澄ます修行」へと昇華させるために生まれました。QWERTYの喧騒を離れ、最も効率的なDvorak配列のフロー（没入感）を見つけてください。

## ✨ 主な特長
- **Zen Interface**: 視覚的なノイズを排除した、Wordle風の洗練された仮想キーボード。
- **Zero-Friction Learning**: 物理キーボードと仮想キーボードがリアルタイムに連動。Shiftキーの挙動も完璧に再現。
- **Personalized Training**: 右上の「Load Texts」から、自分の `.txt` ファイルを読み込み、好きなテキストで「修行」が可能。
- **Monkeytype-style Flow**: スペースキーによる単語スキップ機能を搭載。未入力箇所は自動的にミス判定され、リズムを崩さず練習できます。
- **Printable Layout Map**: 右上の「Dvorak PDF」から、印刷可能なA4サイズのキーマップを即座に取得。
- **Lightweight Architecture**: バニラな HTML/CSS/JS のみで構成。ビルド不要で、どの環境でも最高速で動作します。

---

## 🚀 使い方
1. [ZenDvorak 公式サイト](https://zen.torus-studio.tech)にアクセスします。
2. 表示される「禅」の練習文をタイプし、精神を統一してください。
3. 自分の教材を使いたい場合は、右上のボタンから `.txt` ファイルをアップロードします。
4. 打鍵ごとにキーがフラッシュし、あなたの「フロー」を視覚的にサポートします。

## 📁 ディレクトリ構成
- `index.html` — レイアウトとSEOメタデータ。
- `main.js` — 仮想キーボード生成、ファイル処理、タイピング判定ロジック。
- `style.css` — 禅ミニマリズムを体現した視覚設計。
- `default.txt` — 禅の哲学を綴った初期練習文。
- `assets/` — 高品質なDvorak配列PDFリソース。
